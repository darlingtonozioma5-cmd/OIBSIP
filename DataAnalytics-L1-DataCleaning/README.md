# Data Cleaning and Quality Assessment

**Oasis Infobyte Internship – Data Analytics | Level 1, Task 3**

## 1. Project Overview
This project focuses on identifying, assessing and correcting data-quality issues in a retail transaction dataset using Python.

## 2. Dataset Description
The project uses the UCI Online Retail dataset, which contains transaction records from a UK-based online retail business.

Dataset source: [UCI Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)

## 3. Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 4. Data Quality Issues Investigated
- Missing values
- Duplicate records
- Inconsistent text formatting
- Incorrect data types
- Invalid unit prices
- Potential outliers
- Returned transactions

## 5. Data Cleaning Methods
- Inspected missing values and data types.
- Standardised column names and text fields.
- Converted dates and numerical columns to appropriate data types.
- Removed duplicate records.
- Handled missing essential transaction information.
- Flagged returns and potential outliers for investigation.
- Exported the cleaned dataset.
